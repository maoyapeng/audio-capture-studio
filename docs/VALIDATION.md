# 0.1 验证记录

验证环境：Linux，Python 3.12.10，PySide6 6.9.3，Qt offscreen。

运行命令：`python -m unittest discover -s tests -v`。

9 项自动测试通过，覆盖：

- 两台模拟输入分别保存 8 通道 / 2 通道文件，并检查信号、采样率和文件内容。
- USB 输入断开时保留有效的部分录音，报告异常。
- 探测所选采样格式的可用通道数，不静默减少通道。
- 采集信息不写入密码；Windows 文件名特殊字符和保留名处理。
- 远程终端命令回显不被误判为采集结束；结束后才取回文件。
- 每次远端输出使用唯一文件名，避免取回旧文件。
- 远程文件通道参数不符时不标为成功，保留下载内容。
- 桌面界面选择设备、开始 / 停止，四台演示设备分别生成文件及完整采集清单。

已人工查看 Qt 实际窗口截图，检查 USB 通道面板和远程日志面板。

尚未验证：Windows 真实 USB 驱动与热插拔、多设备长时间压力、真实 SSH / Telnet / ADB 设备和网络故障、Windows EXE 打包。远程流程使用受控传输对象测试，不代表已连接真实设备。
